## What an agent can actually call

FERMÀT ships **no public REST API and no OpenAPI**. Its two machine surfaces are:

1. **FERMÀT Platform MCP server** — a remote, OAuth-protected Model Context Protocol server.
   - Endpoint: `https://mcp.fermatcommerce.com/mcp/fermat-mcp` (Streamable HTTP, POST only)
   - Auth: OAuth 2.1 authorization-code + PKCE (S256), dynamic client registration supported.
     Sign in with existing FERMÀT platform credentials; the provider names Auth0 as the IdP.
   - Access: **customer-only** and **read-only**. The provider states write capabilities are
     "coming soon". An anonymous `tools/list` returns JSON-RPC `-32001`.
   - 64 tools across 12 documented modules: Product Catalog, Funnel Analytics, Ad Performance,
     Destination Insights, Experiments, Session & Behavioral, Anomaly & Friction, Branding,
     Offers, Bundles, Product Pages, and Pierre AI (a natural-language BI agent).
   - Full tool list with descriptions: `mcp/fermat-mcp.yml`
2. **FERMÀT Pixel v2** — a first-party browser ES module a brand embeds to emit commerce events.
   - Loader: `https://static.clairedefermat.com/pixel/v2/claire.mjs` (unpinned)
   - API: `window.fermat({ method: "init" | "track" | "status", ... })`
   - Six documented events: `page_view`, `view_product`, `add_to_cart`, `remove_from_cart`,
     `begin_checkout`, `purchase`. Derived event schema: `asyncapi/fermat-pixel-asyncapi.yml`

`api.fermatcommerce.com` runs a Kong gateway but exposes **no public route** — every path returns
`{"message":"no Route matched with those values"}`. Do not treat it as an API base URL.
